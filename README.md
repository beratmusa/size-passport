# Size Passport 📏

> An AI-powered Size Recommendation Shopify App designed to reduce apparel returns and boost shopper confidence.

**Size Passport** is a comprehensive Shopify application that integrates seamlessly into merchant storefronts as a Theme App Extension. It features an intelligent **Smart Fit Profiler** and an **AI Size Engine** that analyzes shopper profiles against product size charts to recommend the perfect fit.

The app also provides a robust merchant dashboard built with Remix, offering real-time product synchronization and an Analytics Dashboard to track ROI (Return on Investment) and estimated returns saved.

## ✨ Key Features

### For Shoppers (Frontend Widget)
*   **Smart Fit Profiler:** An interactive, multi-step widget that collects shopper body measurements and fit preferences.
*   **AI Size Engine:** Advanced sizing algorithm that normalizes measurements (e.g., half vs. full circumference) and calculates an "AI Fit Score" to predict the best size.
*   **Dynamic Theme Extension:** A deeply integrated storefront block, allowing customizable alignment, scaling, and styling directly from the Shopify Theme Editor.
*   **Responsive UI:** Mobile and desktop-optimized size recommendation displays.

### For Merchants (Admin Dashboard)
*   **Analytics & Return Metrics:** A soft pastel UI dashboard tracking crucial KPIs:
    *   AI Recommendations Shown
    *   AI-Assisted Cart Adds
    *   Estimated Returns Saved (based on industry benchmarks)
*   **Product Sync System:** One-click synchronization of Shopify store products into the app's database using the Shopify GraphQL Admin API.
*   **Size Chart Management:** Automated sorting for size variants (e.g., XS = 2, M = 4, XL = 6) and normalization of size labels.
*   **Event Tracking:** Deeply integrated interceptors tracking form submissions and cart events across modern Shopify themes (Dawn, Horizon, etc.).

## 🏗️ Architecture & Tech Stack

This project is built using a modern, decoupled architecture:

*   **`frontend/` (Storefront Widget):**
    *   React.js, Vite, Tailwind CSS
    *   Generates a bundled asset (`size-passport.js`) that is injected into the Shopify Theme.
*   **`size-passport-app/` (Shopify Admin App & Backend):**
    *   Remix framework, Node.js, Prisma ORM
    *   Shopify App Bridge & Polaris UI for the admin interface.
    *   Webhooks for real-time `products/create` and `products/update` events.
*   **Database:**
    *   Supabase (PostgreSQL) with Row Level Security (RLS) for analytics tracking.

## 🚀 Getting Started

### Prerequisites
*   Node.js (v18+)
*   A Shopify Partner Account and a Development Store
*   A Supabase Account / Database

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/size-passport.git
    cd size-passport
    ```

2.  **Setup the Frontend Widget:**
    ```bash
    cd frontend
    npm install
    # Build the widget (Mandatory after any frontend changes)
    npm run build
    ```
    *Note: The Shopify app extension relies on the bundled assets generated by this build process.*

3.  **Setup the Shopify App:**
    ```bash
    cd ../size-passport-app
    npm install
    ```

4.  **Environment Variables:**
    Create a `.env` file in the `size-passport-app/` directory. You will need your Shopify API keys and Supabase credentials:
    ```env
    SHOPIFY_API_KEY="your_api_key"
    SHOPIFY_API_SECRET="your_api_secret"
    SHOPIFY_APP_URL="your_ngrok_or_tunnel_url"
    SCOPES="write_products,read_products"
    DATABASE_URL="your_supabase_connection_string"
    ```

5.  **Database Migration:**
    ```bash
    npx prisma generate
    npx prisma db push
    ```

6.  **Run the Development Server:**
    ```bash
    npm run dev
    ```

## 🛠️ Development Workflow

*   **Frontend Modifications:** Any changes made inside the `frontend/` directory require running `npm run build` within that folder to update the widget bundle.
*   **App Modifications:** Run the Remix dev server in `size-passport-app/` to develop the admin dashboard and backend webhooks.
