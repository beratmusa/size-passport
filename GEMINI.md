# Project Workflow

## Frontend Builds
- **Mandate:** Perform a frontend build after EVERY code change in the `frontend/` directory.
- **Reason:** The Shopify app extension relies on the bundled assets (e.g., `size-passport.js`) generated by the frontend build process.
- **Command:** `cd frontend && npm run build` (or the equivalent build command defined in `frontend/package.json`).

## Git Practices
- Do not stage or commit changes unless explicitly requested.
- Always check `git status` before finishing a task.
